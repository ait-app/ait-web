把你熟悉的编程 Agent、分布在不同机器上的项目，以及每天使用的设备连接起来。Ait 给你一个统一的工作入口：选择工具、安排任务、跟进进度，再检查结果。

## 多个 Agent，统一使用

Ait 支持 **Codex、Claude Code、OpenCode、DeepSeek Harness、Antigravity CLI、Pi、Oh My Pi 和 MiniMax Code**。你可以在同一个界面使用不同的 Agent，按任务选择合适的工具、模型和权限选项。

继续使用各 Agent 已有的登录与配置，把熟悉的工具带进 Ait。在一个项目里使用多个 Agent，或为不同项目选择不同工具，都沿用同一套会话管理方式。各 Agent 的接入方式和能力见 [Agent 接入](/zh/docs/providers/)。

## 多台电脑和服务器，一个界面管理

Ait 可以**同时连接并管理多台桌面电脑和服务器**，把各主机上的项目、工作区和 Agent 会话集中到一个界面。你可以查看所有主机的工作区，也可以按主机筛选，专注于其中一台机器。

例如，让本机上的 Agent 修改页面，让服务器上的另一个 Agent 运行构建，再到办公室电脑的工作区查看已有任务。各台机器可以同时工作，你在同一个界面跟进进度、发送消息、查看文件或操作终端。

每台主机保留自己的开发环境与项目目录，你可以根据项目需要决定任务在哪台机器上运行。连接方式见 [连接与数据](/zh/docs/connection/)。

## 换一块屏幕，继续同一件事

在电脑上安排任务，离开桌面后用手机查看进度、补充要求或处理审批。临时使用另一台电脑时，打开 [Ait Web 界面](https://aitapp.cn/)，也能连接原来的主机继续工作。

桌面、Android、iOS 和 Web 访问的是主机上已有的工作区与会话。换设备后，任务上下文仍然保留，项目也无需复制到手机。保持工作主机唤醒、服务可用，就可以从方便的设备继续。安装方式见 [平台支持](/zh/docs/platforms/)。

## 从提出任务，到检查和提交结果

会话、文件、Diff 和终端放在同一个工作区里。你可以描述想要的改动，跟随 Agent 的执行过程，打开文件与差异检查修改，再在终端运行项目的构建或测试命令。

需要调整时，带着检查结果继续对话；确认完成后，再进行提交或拉取请求操作。一次任务所需的信息和工具始终在一起，减少来回切换。了解 [工作区的完整流程](/zh/docs/workspaces/)。

## 多个任务，同时推进

把独立任务分别交给不同 Agent，同时推进功能开发、问题修复或代码审查。可以使用同一种 Agent，也可以按任务搭配不同工具与模型。

同一仓库需要并行修改时，用 **Git worktree** 为任务准备独立目录与分支，分别检查 Diff、运行验证，再决定合并哪些结果。具体用法见 [Git worktree](/zh/docs/workspaces/#git-worktree)。

## 中央中继，让远程连接更省心

工作主机与访问设备分别连接 Ait 的**中央中继服务**。登录同一账户即可发现和连接在线主机，无需公网 IP、路由器端口转发，也不要求两端处于同一局域网。

主机通过出站连接接入服务，减少对路由器和入站网络配置的依赖；连接保活与自动重连帮助恢复中断。当前在线工作区通过 Hub 访问，文件下载使用独立通道。连接方式与恢复条件见[连接与数据](/zh/docs/connection/)。

更简单的接入、稳定的连接和更少的建连开销，共同服务于日常远程工作。实际延迟取决于两端网络和到中继节点的距离。设置步骤见 [连接与数据](/zh/docs/connection/)。

## 轻巧的 daemon，适合小内存服务器

Ait 的后台服务用 **Rust** 编写，以独立可执行文件运行。服务器无需启动桌面应用，也无需为 Ait daemon 单独安装 Node.js 运行时，减少常驻环境的负担，把更多资源留给 Agent 和项目工具。

小内存 Linux 服务器或常开的 Mac 都可以作为工作主机。按 [独立 daemon](/zh/docs/daemon/)指南完成安装和机器授权，即可无人值守运行；主机配置仍需满足所选 Agent、并发任务与项目工具的资源需求。

## 任务跑在自己的主机上

项目文件、开发环境和 Agent 运行在你选择的电脑或服务器上，其他设备通过连接访问这个环境。只在本机使用时，无需登录 Ait 账户。

中央中继负责转发连接，Agent 则按自己的配置访问模型服务。你继续管理各 Agent 的登录、订阅与模型选择；Ait 不包含模型订阅。数据与凭据的说明见 [连接与数据](/zh/docs/connection/)。

从 [快速上手](/zh/docs/quick-start/)开始，把第一个 Agent 和项目接入 Ait。

## 创建一项任务

1. 从工作区的 **新建 → 定时任务** 打开任务列表并选择新建。也可在全局定时任务页选择主机、项目和工作区。
2. 从模板或空白开始，填写名称和提示词。任务使用所选工作区的实际目录。需要隔离时，请在对应 Worktree 中创建。
3. 选择当前工作区的已有 Agent，或每次运行新建 Agent。新建时可选择在工作区保留会话，或在结束后归档会话（默认）。归档会话不会归档工作区。
4. 设置固定间隔，或五字段 Cron 和 IANA 时区。默认运行一次，留空则不限次数。成功、失败、手动运行均计入次数。可设置首次触发和截止时间。

例如，使用 `0 9 * * 1-5` 和 `Asia/Shanghai` 在工作日 9 点运行，让 Agent 汇总最近的项目变更。

## 查看结果与处理失败

打开运行历史查看输出或进入对应会话。用 **立即运行** 验证配置。暂停阻止后续自动触发，已开始的运行会继续。运行结束后才可删除任务或修改执行目标。

调度在工作主机的 daemon 上执行。关闭客户端不会停止它，主机离线或 daemon 停止时则不会执行。周期任务跳过错过的触发。单项任务不会重叠运行，目标 Agent 忙碌或等待权限时，本次运行会失败。查看记录并处理阻塞后再重试。

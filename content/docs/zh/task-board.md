从侧栏或命令中心打开 **任务总览**。看板汇集当前已连接主机上的 Agent。可按主机或项目筛选，也可搜索标题、模型或分支。

## 看懂任务状态

| 状态 | 含义 |
| --- | --- |
| 待处理 | 等待权限审批或回答 |
| 运行中 | 正在初始化或执行 |
| 待查看 | 有未读结果、执行失败，或原生子任务状态尚未确认 |
| 已完成 | 没有正在执行的工作、待输入事项或未读提醒 |

展开父任务可查看子任务。父任务显示整棵任务树最需要关注的状态。部分原生子任务只能查看，可用操作取决于 Provider 和主机版本。

## 处理任务

1. 选择卡片查看最近回复、权限请求及子任务。
2. 在卡片中处理可用的审批或计划确认。若 Agent 提问，打开任务详情中的问答表单。
3. 选择 **打开** 回到工作区。也可停止支持此操作的任务，或标记为已查看。清除提醒不会改变任务的失败状态。
4. 当任务及其子任务都没有正在执行的工作或待输入事项时，可将其归档。

离线主机可能仍显示最近状态。重新连接后再审批、停止或归档任务。定期触发的工作在[定时任务](/zh/docs/automation/)中管理。

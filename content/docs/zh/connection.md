Ait 将运行和连接分开：工作主机运行 daemon 与 Agent，客户端连接主机，访问工作区与会话。远程使用时，工作电脑及其服务需要保持在线。

## 选择正确的入口

| 用途 | 地址 |
| --- | --- |
| 官网、下载与文档 | [ait-app.com](https://ait-app.com/) |
| 账户与 Web 客户端入口 | [aitapp.cn](https://aitapp.cn/) |
| 应用默认账户 API | `https://aitapp.cn/api` |
| 本机开发 daemon | `127.0.0.1:7316` |

官网不是账户 API，`/hosts` 管理页面也不能填入 API 地址。

## 通过账户连接

桌面、Android 与 iOS 使用应用配置的账户服务地址，具体以 **Service settings** 中的配置为准。账户控制台内置的 Web 客户端使用该控制台同源的 `/api` 服务。官网 `https://ait-app.com` 用于产品介绍和文档，不是账户 API 地址。

1. 在工作电脑打开 **在线服务 → 登录 / 注册**，完成托管登录流程并返回 Ait。
2. 确认工作主机已与在线服务同步；如之前停止过同步，请在主机连接设置中重新启用。
3. 在另一台桌面设备、Android 或 iOS 上登录同一账户与服务，打开 **在线服务** 或 **Add Host**。
4. 从在线主机列表选择工作电脑，添加到已保存主机。

主机列表定期刷新，不显示当前机器。移动设备只作为客户端，不发布手机为工作主机。桌面与 Android 使用系统浏览器完成托管登录，iOS 使用系统认证窗口。网页访问可从 [aitapp.cn](https://aitapp.cn/) 登录并进入 Web 客户端。账户中继无需两端处于同一局域网，也无需给工作电脑设置公网端口转发。

使用自建账户服务时，在 **Service settings** 中填写 API 基础地址。留空使用默认的 `https://aitapp.cn/api`。新版客户端会迁移已保存的旧官方地址，包括带 `:8443` 的地址；自定义服务地址保持原值。两端需要使用同一服务及账户。

## 直接连接

桌面与移动端可以使用直接连接，本地开发的 Web 客户端也使用这种方式。账户控制台集成的 Web 客户端提供在线服务连接。直接连接时需要工作主机地址、端口和 daemon 访问令牌。

本地开发的默认 daemon 监听地址为 `127.0.0.1:7316`。此地址只能在对应主机上使用；另一台设备需要能够访问的具体主机地址。监听与浏览器 Origin 设置见 [服务配置](/zh/docs/configuration/)。

## 凭据分别管理

- **Ait 连接令牌**用于客户端与 daemon 的认证。
- **Agent 服务凭据**由 Codex、Claude Code、OpenCode 等原生程序保存，用于访问各自服务。
- **账户登录凭据**在原生客户端中通过平台安全存储保存；安全存储不可用时，重启后可能需要重新登录。Web 客户端使用浏览器存储维持登录。

浏览器先交换短时一次性连接票据，再升级 WebSocket。服务 Bearer 不放入 URL。

## 数据留在工作主机

项目文件与 Agent 运行时保留在工作主机。桌面默认服务数据目录为 `~/.ait-server-desktop`，独立 daemon 默认目录为 `~/.ait-server`。

本地运行不表示模型请求永远不出网。Agent 会按自身配置与对应供应商通信，使用远程模型时应参考供应商的数据政策。远程客户端通过所选连接方式读取主机上的文件与会话。

## 断开与恢复

新版 Android 和 iOS 客户端切到后台后，会尝试保留账户中继连接和正在进行的下载最多 2 分钟；期间返回可复用仍健康的连接。超过窗口后暂停账户网络活动，回到前台重新验证并连接。系统可能提前挂起应用或中断网络，这不是后台执行保证。

连接中断不会把工作电脑上的 Agent 搬到手机，也不等于取消主机上的任务。重新连接后查看会话状态，避免不确定上次是否发送成功时重复提交任务。

桌面退出后能否继续使用取决于主机的服务和在线授权。**Keep daemon running after quit** 可以保留本地 daemon，但需要长期无人值守的在线主机时，应按[服务配置](/zh/docs/configuration/)使用 headless 模式。

更完整的协议、关闭与数据目录说明见 [daemon 手册](https://github.com/ait-app/ait/blob/main/docs/operations/daemon.md)。

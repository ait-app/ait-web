Ait 将运行和连接分开：工作主机运行 daemon 与 Agent，客户端连接主机，访问工作区与会话。远程使用时，工作电脑及其服务需要保持在线。

## 选择正确的入口

| 用途 | 地址 |
| --- | --- |
| 官网、下载与文档 | [ait-app.com](https://ait-app.com/) |
| 账户与 Web 客户端入口 | [aitapp.cn](https://aitapp.cn/) |
| 应用默认账户 API | `https://aitapp.cn/api` |
| 本机开发 daemon | `127.0.0.1:7316` |

官网不是账户 API，`/hosts` 管理页面也不能填入 API 地址。

## 通过账户连接

在 macOS 或 Linux 上使用内置 daemon 时，无需登录 Ait 账户。要通过在线服务从另一台设备连接，在欢迎页、**设置 → 应用 → 在线服务** 或 **添加主机 → 在线服务** 发起登录。

桌面、Android 与 iOS 使用应用配置的账户服务地址，具体以 **Service settings** 中的配置为准。托管 Web 客户端部署在网站根路径，使用同源的 `/api` 服务，管理控制台位于 `/dash`。官网 `https://ait-app.com` 用于产品介绍和文档，不是账户 API 地址。

1. 在工作电脑打开 **在线服务 → 登录 / 注册**，完成托管登录流程并返回 Ait。
2. 确认工作主机已与在线服务同步；如之前停止过同步，请在主机连接设置中重新启用。
3. 在另一台桌面设备、Android 或 iOS 上登录同一账户与服务，打开 **在线服务** 或 **Add host**。
4. 从在线主机列表选择工作电脑，添加到已保存主机。

新版客户端通过账户状态通道接收主机列表与可连接状态更新；列表不显示当前机器。移动设备只作为客户端，不发布手机为工作主机。桌面与 Android 使用系统浏览器完成托管登录，iOS 使用系统认证窗口。网页访问可从 [aitapp.cn](https://aitapp.cn/) 登录并进入 Web 客户端。账户中继无需两端处于同一局域网，也无需给工作电脑设置公网端口转发。

使用自建账户服务时，在 **Service settings** 中填写 API 基础地址。留空使用默认的 `https://aitapp.cn/api`。新版客户端会迁移已保存的旧官方地址，包括带 `:8443` 的地址；自定义服务地址保持原值。两端需要使用同一服务及账户。

## 直接连接

桌面和移动客户端可以不登录账户，通过可信局域网或 VPN 直连。aitapp.cn 上的 **Ait for Web** 仅支持在线服务。本地开发版 Web 客户端可按[浏览器来源设置](/zh/docs/configuration/#本机浏览器来源)直连。

- **无头工作主机**：独立 `aitd` 默认监听 `127.0.0.1:7316`。使用以下命令（或 `AIT_SERVER_LISTEN`）绑定实际局域网地址：

  ```sh
  aitd run --listen 192.168.1.10:7316
  ```

  读取 `<data-dir>/local-api.token` 或使用启动时指定的 `AIT_SERVER_TOKEN`。仅向可信网段放行对应 TCP 端口，参见[独立 daemon 局域网配置](/zh/docs/daemon/#不登录直接连接局域网主机)。
- **macOS / Linux 桌面工作主机**：打开本机主机设置中的 **守护进程** 区域，填写**监听地址**和**端口**，再重启 daemon。桌面默认用 `127.0.0.1:0` 分配本机端口。选择实际的局域网地址和固定端口（如 `7316`），同样准备令牌并限制防火墙来源。
- **连接设备**：选择 **添加主机 → 直接连接**，填写工作主机的 **Host**、**端口**和**访问令牌**。如需使用 SSL，请在 daemon 前配置 TLS 终止代理。

### SSH 隧道

如果只能通过 SSH 安全访问无头主机，可以让 `aitd run` 保持默认回环监听。在连接端的电脑上运行：

```sh
ssh -N -L 127.0.0.1:7316:127.0.0.1:7316 user@working-host
```

将 `user@working-host` 换成 SSH 用户和主机。在这台电脑的 Ait 中直连 `127.0.0.1`、端口 `7316`，填写远端 daemon 的访问令牌。若本机端口已被占用，换一个本机转发端口并在客户端填新端口。保持 SSH 会话运行，主机无需向公网开放 daemon 端口。

## 凭据分别管理

- **Ait 连接令牌**用于客户端与 daemon 的认证。
- **Agent 服务凭据**由 Codex、Claude Code、OpenCode 等原生程序保存，用于访问各自服务。
- **账户登录凭据**在原生客户端中通过平台安全存储保存；安全存储不可用时，重启后可能需要重新登录。Web 客户端使用浏览器存储维持登录。

浏览器先交换短时一次性连接票据，再升级 WebSocket。服务 Bearer 不放入 URL。

## 数据留在工作主机

项目文件与 Agent 运行时保留在工作主机。默认数据目录为 `~/.ait`；如果已有旧目录，会按 `~/.ait`、`~/.ait-server-desktop`、`~/.ait-server` 顺序选择第一个存在的路径。

本地运行不表示模型请求永远不出网。Agent 会按自身配置与对应供应商通信，使用远程模型时应参考供应商的数据政策。远程客户端通过所选连接方式读取主机上的文件与会话。

## 断开与恢复

新版 Android 和 iOS 客户端切到后台后，会尝试保留账户中继连接和正在进行的下载最多 2 分钟；期间返回可复用仍健康的连接。超过窗口后暂停账户网络活动，回到前台重新验证并连接。系统可能提前挂起应用或中断网络，这不是后台执行保证。

连接中断不会把工作电脑上的 Agent 搬到手机，也不等于取消主机上的任务。重新连接后查看会话状态，避免不确定上次是否发送成功时重复提交任务。

当前源码由 daemon 自主管理机器授权、节点续租和在线重连。只要 daemon 仍在运行且授权有效，退出客户端不会撤销机器授权；桌面的 **Keep daemon running after quit** 可保留本地进程。显式断开主机同步会关闭在线连接并清除机器授权，之后需要重新授权。需要长期在线且不依赖桌面生命周期时，可运行[独立 daemon](/zh/docs/daemon/)。

当前桌面、Android、iOS 与 Web 的普通在线业务只通过 Hub；Hub 不可用时会明确失败，不再回退旧业务传输。文件下载保留独立 Relay 通道。遇到版本不一致时同时核对客户端、daemon 与中心服务，详见 [ADR-204](https://github.com/ait-app/ait/blob/main/docs/decisions/clients/adr-204-hub-only-online-business-transport.md)。

更完整的协议、关闭与数据目录说明见 [daemon 手册](https://github.com/ait-app/ait/blob/main/docs/operations/daemon.md)。

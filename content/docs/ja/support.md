## Ait サポートへの連絡

アプリの問題、アカウントや接続に関するヘルプ、一般的なフィードバック、機能のリクエストは、**[support@ait-app.com](mailto:support@ait-app.com)** までメールでお送りください。Ait にサインインしたり GitHub アカウントを作成したりしなくても、ご連絡いただけます。

プライバシーに関するご質問やアカウント・データの削除については、[プライバシーポリシー](/ja/privacy/)と[削除の手順](/ja/privacy/#data-deletion)をご覧ください。

## Ait ベータに参加する

**Android / Google Play クローズドテスト**: Google Play で使用している Google アカウントのメールアドレスを **[support@ait-app.com](mailto:support@ait-app.com)** に送り、Android のクローズドテストへの参加を希望する旨をお伝えください。承認されたら、同じアカウントで [Ait クローズドテストに参加](https://play.google.com/apps/testing/dev.ait.mobile)し、オプトインしてアプリをインストールします。リンクを開くだけでは、自動的にアクセス権は付与されません。内部テストに参加している場合は、クローズドテストに参加する前に内部テストから退出してください。

**iOS / iPadOS**: [対応プラットフォーム](/ja/docs/platforms/)にある公開の TestFlight 招待から参加してください。メールでの申請は不要です。このページでは、各プラットフォームのインストール手順と参加条件も説明しています。

## 報告を送る前に

調査のため、次の情報を含めてください。

- Ait のバージョンとインストール元（TestFlight、Google Play、GitHub、ソースからのビルドなど）。
- デバイスのモデルとオペレーティングシステムのバージョン。リモート接続の場合は、作業ホストのシステムも記載してください。
- 期待した動作、実際に起きたこと、問題を再現する手順。
- 該当する場合は、接続方法（ローカル、ダイレクト、アカウントリレー）とエージェントのプロバイダー。
- パスワード、アクセストークン、個人情報、非公開のプロジェクト内容を削除したエラーメッセージやスクリーンショット。

ログは、必要な場合に限り関連する部分のみを送ってください。プロジェクトディレクトリ全体、アカウントのパスワード、認証コード、API キーをメールで送らないでください。再現可能な製品のバグは、[GitHub の issue トラッカー](https://github.com/ait-app/ait/issues)でも報告できます。issue は公開されるため、アカウントやプライバシーに関するリクエストはメールでお送りください。

## アプリ診断情報のエクスポート

設定の**アプリ診断**を開いて診断を実行し、`.txt` レポートをエクスポートします。デスクトップとブラウザーのクライアントではファイルがダウンロードされ、Android と iOS ではシステムの共有シートが開きます。レポートを問題と照合できるよう、問題が発生した時刻も記載してください。

レポートでは、一般的な認証情報や非公開のフィールドの除去が試みられますが、共有する前に内容を確認してください。診断情報が自動的にアップロードされたり、公開 issue が作成されたりすることはありません。`unavailable`、`truncated`、`timeout` は、証拠が不完全であることを示しており、確認が成功したことを意味しません。

デーモンは、ローカルのインシデント証跡を最大 7 日間、20 ファイルかつ 5 MiB の上限内で自動的に保持します。容量の上限により、それより早く削除される場合があります。エクスポートしたファイルはお客様の管理下にあります。障害の発生後は、早めにエクスポートしてください。収集の詳細については[診断マニュアル](https://github.com/ait-app/ait/blob/main/docs/operations/diagnostics.md)を参照してください。

## よくある質問

### 作業用コンピューターが表示されない

作業用コンピューターがスリープしておらず、ネットワークに接続されていて、ホストの同期が有効になっていることを確認してください。両方のデバイスで同じ Ait アカウントとサービスアドレスを使用する必要があります。既定のアカウント API は `https://aitapp.cn/api` です。ホスト一覧には現在のマシンは含まれません。同期を手動で停止した場合は、再度有効にして一覧を更新してください。設定の詳細は[接続とデータ](/ja/docs/connection/)を参照してください。

現在のソースでは、デーモンが自身のオンラインプレゼンスを維持します。デーモンが動作し続けていること、マシンの認可が有効であること、ホストの同期が明示的に切断されていないことを確認してください。Linux や macOS のホストを常時稼働させるには、[スタンドアロンデーモン](/ja/docs/daemon/)を使用します。古いクライアントやデーモンでは動作が異なる場合があるため、アップグレードの際は両方のバージョンを確認してください。

### 直接接続に失敗する

ホストのアドレス、ポート、デーモンのアクセストークンを確認してください。`127.0.0.1` は現在使用しているデバイス自身を指すため、スマートフォンからは作業用コンピューターに到達できるアドレスが必要です。ネットワークとリスナーの設定は[サーバー設定](/ja/docs/configuration/)で確認してください。トークンをサポートに送らないでください。

### エージェントが利用できない、またはサインインを求められる

まず、作業用コンピューターのターミナルで CLI が単独で動作し、サインイン済みであることを確認してから、アプリ診断でバージョンとエラーを確認してください。インストール、アップグレード、実行ファイルのパスの変更を行ったら、ホストのデーモンを再起動します。スマートフォンのアプリを開き直しても、ホストの環境は更新されません。

モデル、モード、権限のオプションは現在のプロバイダーから取得されるため、CLI のバージョンによって異なる場合があります。OpenCode は初回起動時にカタログを初期化します。DeepSeek Harness の Web プロファイルとデスクトッププロファイルでは設定が異なる場合があります。Antigravity には AGY CLI が必要です。各連携の詳細は[エージェントのセットアップ](/ja/docs/providers/)を参照してください。Ait のアカウントとプロバイダーのサインインは別のものです。モデルのサブスクリプション、クォータ、課金はプロバイダーが管理します。

### アプリから離れると接続が切れる

新しい Android と iOS のクライアントは、ネットワーク動作を一時停止するまで、アカウントのリレー接続とダウンロードを最大 2 分間維持しようとします。オペレーティングシステムによって、それより早くアプリが停止される場合もあります。アプリに戻ると、接続が再確認されます。作業用コンピューターはスリープさせないでください。スマートフォンの接続が切れても、そのホスト上のエージェントが自動的にキャンセルされることはありません。

配信状況が不確かなメッセージを再送する前に、再接続後にセッションを確認してください。フォアグラウンドでも接続が切れ続ける場合は、診断情報をエクスポートし、両方のバージョン、接続方法、障害が発生した時刻を添えてください。

### サインインできない、またはアカウントの有効期限が切れた

サインインサービスのパスワード回復や連絡先の確認フローが利用できる場合は、それをご利用ください。Ait アカウントへのアクセスや有効期限の問題については、登録済みのメールアドレスまたは電話番号を添えてサポートにメールしてください。パスワードや認証コードは記載しないでください。

### アカウントやデータを削除したい

[アカウントとデータの削除手順](/ja/privacy/#data-deletion)に従ってください。サインアウトやアプリのアンインストールでは、オンラインアカウントや作業用コンピューター上のプロジェクトデータは削除されません。

## Ait の改善に協力する

問題の再現、ドキュメントの修正、コードの貢献を行う場合は、[コントリビューション](/ja/docs/contributing/)と[ローカル開発](/ja/docs/development/)をお読みください。製品の変更は `ait-app/ait` に、Web サイトと公開ドキュメントの変更は `ait-app/ait-web` に送ってください。

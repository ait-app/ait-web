## セッションをインポート・再開する

サイドバーの **セッションをインポート** を開きます。サインイン中はアカウントメニューにあります。ホスト、プロバイダー、セッションを選んで対応するワークスペースを開きます。Codex、Claude Code、DeepSeek Harness、Pi、Oh My Pi はネイティブ履歴のインポートに対応します。OpenCode は CLI の ACP 対応状況によります。Antigravity と MiniMax Code は Ait のセッションを再開できますが、外部履歴全体のインポートには対応していません。再開前に、同じセッションに書き込む別プロセスを停止してください。[エージェントの設定](/ja/docs/providers/)

## 主会話の横で質問する

既存の会話で `/btw` または `/btw 質問文` を入力します。主タスクの実行中も別ウィンドウで続けて質問できます。最初の質問時に保存済みの文脈を使用し、やり取りは別の履歴に保存します。**展開** で新しい通常セッションの下書きに引き継げます。

BTW は対応クライアントと Unix ホスト上で Codex、Claude Code、OpenCode、Pi、Oh My Pi をサポートします。別セッションへの引き継ぎには[ワークスペースのメモ帳](/ja/docs/workspaces/#ワークスペースのメモ帳)を使えます。

## Goal を確認・操作する

ネイティブ Goal に対応する Codex または Oh My Pi では、ホストが報告する目標と、編集、一時停止、再開、消去などの操作が入力欄に表示されます。統合機能メニューと Goal 表示には v0.2.26 のクライアントと対応ホストが必要です。

## タイムラインを書き出す

**コンテキストの詳細** から Markdown または HTML を選択し、保存済みの全項目、または会話と音声の文字起こしだけを書き出せます。書き出し中も作業は続きます。添付は参照のみ保存されます。旧ホストでは使えない場合があります。上限を超えるとエラーになります。

## 音声入力とリアルタイム音声

音声入力は標準でホスト側が処理します。オフラインモデルの初回準備にはインターネット接続が必要です。リアルタイム音声は Codex のバージョン、認証、クライアント、ホスト構成の条件が揃うと利用できます。デスクトップと Web は WebRTC を使用します。その他のクライアントでは API キーが必要な場合があります。[音声の設定](https://github.com/ait-app/ait/blob/main/docs/operations/speech.md)

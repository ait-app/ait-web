ワークスペースごとに Bot を 1 つ設定できます。Bot は同じワークスペースのエージェントに作業を渡し、完了、失敗、回答待ちを知らせます。利用可否はクライアントとホストのバージョンによります。

## 設定と接続

1. **設定 → アプリ情報 → 実験的な機能** をオンにし、ワークスペースの **新規** から **Bot** を選びます。更新を求められたら、作業ホストの daemon を更新します。
2. プロバイダー、モデル、実行オプションを選びます。Bot 設定で許可するエージェントモードとツールグループを確認します。
3. まず Ait 内の会話で試します。外部サービスは Bot 設定でチャンネルを追加し、認証を完了して有効になったことを確認します。
4. 今週のワークスペースの変更をまとめるなど、具体的な作業を依頼します。**タスク** タブで進捗と回答待ちの質問を確認できます。

| チャンネル | 設定と対応範囲 |
| --- | --- |
| Telegram | BotFather のトークンと確認リンクを使い、Start を選びます。グループを有効にするとメンションや返信で起動できます。 |
| Feishu / Lark | 中国版 Feishu は QR コードまたは認証情報、国際版 Lark は専用アプリの認証情報で接続します。グループでは有効化とメンションが必要です。 |
| WeChat | QR コードで接続し、個別チャットで使います。期限切れ後は再接続します。 |
| QQ | QR コードまたは手動で接続します。グループは別途有効にします。QQ の返信可能時間が適用されます。 |
| iMessage | Photon のホスト回線を使い、個別チャットで利用します。 |

以前の送信者リストはメッセージの絞り込みに使われません。グループを有効にする前に公開範囲と起動条件を確認してください。認証情報はチャンネルごとに必要です。[Bot の設定手順](https://github.com/ait-app/ait/blob/main/docs/operations/bots.md)

## 進捗、PR、権限

進捗は通常、依頼元の会話に届きます。元のチャンネルが無効または利用できない場合は Ait 内に届きます。外部の履歴は Bot タブで閲覧できます。Bot を一時停止すると新しい会話の受付が止まります。依頼済みのエージェントは個別に管理してください。

対応バージョンでは、同じリポジトリの GitHub PR または GitLab MR を追跡できます。作業ホストで `gh` または `glab` にログインしてください。タスクの詳細にレビューとチェックの状態が出ます。Bot は発信元や権限に応じてフィードバックを処理します。タスクを取り消すと追跡が止まります。

使える操作はツールグループ、ワークスペースの範囲、プロバイダーのモードで決まります。スクリプトとターミナルは標準で無効です。Bot セッションがユーザーの代わりにプロバイダーの権限を承認することはありません。コマンドやターミナルへのアクセスは作業に必要な範囲で設定してください。

サイドバーまたはコマンドセンターから **タスク一覧** を開きます。接続中のホストのエージェントが表示されます。ホストやプロジェクトで絞り込んだり、タイトル、モデル、ブランチで検索したりできます。

## タスクの状態

| 状態 | 意味 |
| --- | --- |
| 要対応 | 承認または回答を待っている |
| 実行中 | 起動中、または作業中 |
| 要確認 | 未読の結果、実行の失敗、またはネイティブの子タスクの状態が未確認 |
| 完了 | 実行中の作業、未回答の入力、未読の通知がない |

親タスクを展開して子タスクを確認します。親には最も対応が必要な状態が反映されます。一部のネイティブの子タスクは閲覧専用です。操作はプロバイダーとホストのバージョンで異なります。

## タスクを操作する

1. カードで直近の返信、権限リクエスト、子タスクを確認します。
2. カードで承認や計画の確認を行います。質問には詳細画面のフォームから回答します。
3. **開く** を選んでワークスペースで続けます。対応するタスクの停止や未読通知の消去もできます。既読にしても失敗の状態は残ります。
4. 親子ともに実行中の作業や入力待ちがなければ、アーカイブできます。

ホストのオフライン中は前回の状態が表示される場合があります。承認、停止、アーカイブの前に再接続してください。繰り返し作業は[定期タスク](/ja/docs/automation/)で管理できます。

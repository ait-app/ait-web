## 始める前に

**Apple Silicon の Mac または Linux x86_64 のコンピューター**、プロジェクトのディレクトリ、そしてインストールとサインインが済んだエージェント CLI を 1 つ以上ご用意ください。Ait は Codex、Claude Code、OpenCode、DeepSeek Harness、Antigravity CLI に対応しています。設定の詳細は[エージェントのセットアップ](/ja/docs/providers/)をご覧ください。

Ait は各エージェントのサインイン情報とモデル設定をそのまま利用します。モデルのサブスクリプションは含まれていません。エージェントは、タスクを実行するホストにインストールしてください。スマートフォンやブラウザーはそのホストに接続します。

## 1. Ait をインストールする

### デスクトップアプリ（推奨）

[Ait のダウンロードページ](/ja/download/)を開き、お使いのコンピューターに合ったパッケージを選びます。

- **macOS Apple Silicon**：DMG を開き、Ait を「アプリケーション」にインストールして起動します。
- **Linux x86_64**：AppImage または tar.gz をダウンロードし、実行するか展開して、該当するパッケージを起動します。

Ait を開き、ローカルのサービスに接続します。デスクトップアプリは同梱のデーモンを自動的に起動するため、別途サービスをインストールする必要はありません。**ローカルで使う場合、Ait アカウントは不要です。**

インストーラー、中国向けのダウンロードミラー、プラットフォームの詳細は[対応プラットフォーム](/ja/docs/platforms/)をご覧ください。デスクトップアプリをインストールした場合は、下の「エージェントを接続する」に進んでください。

### サーバー / スタンドアロンデーモン

プロジェクトがクラウドサーバーや常時稼働のホストにある場合は、[スタンドアロンデーモンのガイド](/ja/docs/daemon/)に従って `aitd` をダウンロード、検証、インストールします。その後、タスクを実行するのと同じシステムユーザーで次のコマンドを実行します。

```sh
aitd login
aitd run
```

初回の認可では、ターミナルに Web アドレスと確認コードが表示されます。ブラウザーでそのアドレスを開き、Ait アカウントにサインインして、このマシンを承認してください。デーモンが起動したら、[Ait Web アプリ](https://aitapp.cn/)を開き、同じアカウントでサインインして、オンラインのホスト一覧からマシンを選択します。

インストールガイドのダウンロードとサービスの例は、現在 v0.2.2 を対象としており、`aitd run` を使用しています。古いインストールをアップグレードする場合やソースからビルドする場合は、[バージョンに関する案内](/ja/docs/daemon/#最新ソースとアップグレード)で起動引数を確認してください。

`run` はフォアグラウンドで動作するため、プロセスを終了させないでください。継続して使う場合は、[バックグラウンドサービスの手順](/ja/docs/daemon/#常時稼働させる)に従って systemd または launchd を設定します。エージェント CLI のインストールとプロジェクトファイルの配置も、このホストで行ってください。

## 2. エージェントを接続する

1. 選んだエージェントを**作業ホストのターミナル**で起動します。サインイン済みで、単独でタスクを処理できることを確認してください。
2. Ait に戻り、セッションの作成時にそのエージェントを選びます。既存のネイティブなサインイン情報とプロジェクト設定がそのまま使われます。
3. エージェントが提供するモデルと権限のオプションを選択します。利用できるオプションは、インストールされているバージョンによって異なります。

始めるのに必要なエージェントは 1 つだけです。後から、同じワークスペースに他のエージェントのセッションを追加できます。

> エージェントが表示されない場合は、接続中のホストにその CLI がインストールされ、ターミナルで動作することを確認してください。標準以外の場所にインストールした場合は、[実行ファイルのパス](/ja/docs/providers/#実行ファイルのパスを指定する)をご覧のうえ、対応するデーモンを再起動してください。

## 3. 最初のワークスペースを作成する

1. **プロジェクトを追加する**：作業ホスト上の既存のプロジェクトディレクトリを選択します。
2. **ワークスペースを作成する**：まずは既存のディレクトリで始めます。並行して変更を進めるために別々のディレクトリが必要な場合は、[Git worktree](/ja/docs/workspaces/#git-worktree) を使います。
3. **エージェントのセッションを作成する**：用意したエージェントを選び、範囲を明確にしたタスクを送信します。

まずはプロジェクトの把握から始めましょう。次のプロンプトを試してみてください。

> このプロジェクトを読み、何をするものか、主なディレクトリ、ローカルでの実行方法を説明してください。既存のビルドコマンドやテストコマンドも探してください。まだファイルは変更しないでください。

応答とツールの動作が表示されれば、最初のタスクは完了です。次は、文言の修正や README の更新など、小さな変更をエージェントに依頼し、会話内の権限リクエストに応答してみましょう。

変更後は**ファイルと差分**を確認し、**ターミナル**でプロジェクト自身のビルドコマンドやテストコマンドを実行します。詳しくは[ワークスペース](/ja/docs/workspaces/)をご覧ください。

## 4. 別のデバイスで続ける（任意）

1. 作業用のコンピューターで **オンラインサービス → サインイン / 登録** を開き、Ait にサインインして、ホストの同期が有効になっていることを確認します。無人で動作するデーモンの場合は、前述の `login` の手順でマシンの認可が済んでいます。
2. 別のデバイスで Ait を開き、**同じアカウントとサービス**でサインインして、オンラインのホスト一覧から作業用のコンピューターを選びます。
3. 同じワークスペースを開くと、進捗の確認、メッセージの送信、承認への応答ができます。

接続に使うデバイスを選んでください。

- **ブラウザー**：[Ait Web アプリ](https://aitapp.cn/)を開きます。クライアントのインストールは不要です。
- **iPhone / iPad**：[TestFlight の手順](/ja/docs/platforms/#iphone-と-ipad)に従って公開招待を承諾し、Ait をインストールします。
- **Android**：[Google Play のテスト手順](/ja/docs/platforms/#google-play-クローズドテスト)に従って、まずアクセスをリクエストし、承認された Google アカウントでインストールします。
- **別のコンピューター**：デスクトップアプリをインストールし、同じ Ait アカウントでサインインして、オンラインのホストを選びます。

作業ホストはスリープさせず、Ait のサービスとエージェントを利用できる状態にしておいてください。アカウントリレーを使えば、デバイス同士が同じローカルネットワークにある必要も、ホストが公開ポートを転送する必要もありません。詳しくは[接続とデータ](/ja/docs/connection/)をご覧ください。

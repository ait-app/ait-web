デスクを離れたあと、スマートフォンの画面で何十行もコードを書くことはめったにありません。多いのはもっとピンポイントな用事です。「このブランチの今週の変更点をまとめてほしい」「このエラーがどのコミットで入ったか調べてほしい」「さっき出した PR の CI が通ったか、レビューコメントが付いたか見ておいてほしい」といった類です。

1 行の依頼のために毎回開発クライアントを開いてホストとセッションを選び直すのは大げさですが、かといってフルのシェル権限を持ったボットをチャットグループへ無防備につなぐのも怖いところです。Ait の **Workspace Bot** は、まさにその間を狙っています。

## ワークスペースごとに 1 つ、まずはアプリ内で試せる

Workspace Bot は現在実験的な機能として提供されており、**設定 → アプリ情報 → 実験的な機能** から有効にします。有効にしたあと、ワークスペースの **新規** メニューから **Bot** を選んで作成します（作業ホストのデーモンが古い場合は案内どおり先に更新してください）。

ワークスペースごとに 1 つ設定でき、使うプロバイダー、モデル、許可するエージェントモード、ツールグループを個別に決められます。最初から外部チャットをつなぐ必要はなく、Ait 内蔵の Bot 会話でまず動きを試し、**タスク** タブで進捗や回答待ちの質問を確認できます。

手応えがつかめたら、普段使っているチャットサービスを接続します。現在対応しているのは 5 つです。

- **Telegram**：BotFather のトークンを登録し、確認リンクを開いて Start を押します。グループチャットは個別に有効化し、メンションまたは返信で起動します。
- **Feishu / Lark**：中国版 Feishu は QR コードまたは認証情報の手動入力、国際版 Lark は専用アプリの認証情報を使います。グループは有効化とメンションが必要です。
- **WeChat**：QR コードで接続し、個別チャットのみ対応します。セッションが切れたら再スキャンします。
- **QQ**：QR コードまたは手動設定で接続し、グループは別途有効化します。返信は QQ 側のパッシブ返信可能時間に制約されます。
- **iMessage**：Photon のホスト回線経由で個別チャットのみ対応します。

作業の完了・失敗・確認待ちの連絡は、原則として依頼を出した元の会話へ返ります。外部チャンネルが無効になっていたり到達できなかったりする場合は Ait 内蔵の会話へフォールバックし、外部での履歴も Bot タブから振り返れます。

グループチャットを有効にする前に 1 点だけ注意してください。現在は以前の送信者ホワイトリストによる絞り込みを使わないため、チャットプラットフォーム側で参加範囲と起動条件を確認してからオンにするのが安全です。

## GitHub PR と GitLab MR をそのまま追わせる

作業ホストで `gh` または `glab` にログインしてある場合、PR 追跡に対応したバージョンでは同じリポジトリの GitHub PR や GitLab MR を Bot に追わせられます。

タスク詳細にレビュー状況とチェックの進捗が集約され、発信元と権限に応じてレビューコメントへの対応も進められます。追跡を止めたいときはタスクを取り消すだけです。5 分おきにブラウザをリロードし続ける必要がなくなります。

## 権限をどう区切るか

チャットツールをリポジトリへつなぐとき、一番気になるのは「意図しないコマンドを勝手に走らせないか」という点です。Workspace Bot ができることは、ワークスペースの範囲、プロバイダーのモード、Bot 設定のツールグループの 3 つで決まります。

標準設定で効いているルールが 2 つあります。

1. **スクリプトとターミナルのツールグループは既定でオフ。** コード調査や変更要約、PR の追跡だけでよければオフのまま運用でき、ビルドやテストを回したいワークフローだけ必要に応じて開けられます。
2. **Bot がユーザーの代わりにプロバイダーの権限リクエストを承認することはない。** エージェントが許可を求める操作に差し掛かったら一時停止するので、[タスク一覧](/ja/docs/task-board/) など Ait 本体側で中身を見てから承認・拒否を判断します。

なお、Bot を一時停止すると新しい会話の受付は止まりますが、すでに起動したエージェントのセッションは独立して動き続けるため、ワークスペースやタスク一覧から個別に管理してください。

各チャンネルの認証情報や設定手順は、[Workspace Bot](/ja/docs/bots/) およびリポジトリの [Bot の設定手順](https://github.com/ait-app/ait/blob/main/docs/operations/bots.md) にまとめています。

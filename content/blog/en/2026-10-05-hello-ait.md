Before building Ait, our daily screen looked like this: two terminal tabs running Claude Code and Codex, an editor open to inspect the resulting diffs, and an SSH window into a Linux build machine. Once three or four tasks ran in parallel, half the friction was just hunting for which tab was waiting on a permission prompt—and the moment we walked away from the desk, we had no idea whether a run had finished or stalled.

We did not want another thin API chat wrapper, and we did not want to upload local repos into a cloud sandbox just to get a nicer UI. So we built Ait.

## Use the native agents already on your host

Ait connects to **Codex, Claude Code, OpenCode, DeepSeek Harness, Antigravity CLI, Pi, Oh My Pi, and MiniMax Code** installed directly on your working host.

Each tool keeps its own login, model subscription, `CLAUDE.md`, skills, and MCP config. Ait does not resell model credits or sit between your agent and its model provider. You pick whichever tool fits the task in one interface, and the exact capability differences between CLIs are laid out plainly in [Agent setup](/en/docs/providers/).

## Sessions, diffs, terminals, and Git side by side

Sending a prompt is only the start; you still need to read the diff, run tests, resolve conflicts, and open a PR.

An Ait workspace keeps conversations, files, diffs, terminals, and Git actions in one view. When tasks branch off inside the same repo, spin up a regular or sandboxed worktree; when several hosts and agents are active at once, open the **Task board** to see what needs approval, what is still running, and what is ready to review.

## Runs on your machines, reachable from whichever screen you have

Ait’s backend is a lightweight Rust daemon:

- The macOS and Linux desktop apps start the bundled daemon automatically; local-only use requires no Ait account.
- Headless Linux servers and always-on Mac minis can run the standalone `aitd` executable.
- Sign in to the same account to reach your hosts from desktop (including Windows), iOS, Android, and [Ait for Web](https://aitapp.cn/), or connect directly over a trusted LAN or SSH tunnel without an account.

To try it out, head to [Download](/en/download/), follow the [Quick start](/en/docs/quick-start/) to hook up your first agent, or check the source and recent changes on [GitHub](https://github.com/ait-app/ait).

开始做 Ait 之前，我们日常写代码的桌面长这样：左边两个终端跑 Claude Code 和 Codex，中间开着编辑器看刚才改出来的 Diff，右边还挂着一个 SSH 窗口连着编译机。任务一多，光是切窗口找“哪个 Agent 卡在等我点确认”就要花掉不少精力；离开工位之后，更是完全不知道主机上的活跑完了没有。

我们不想再造一个自己包 API 的聊天壳子，也不想把本地项目传到某个云端沙盒里重新搭环境。于是就有了 Ait。

## 直接接你本机装好的原生 Agent

Ait 目前支持 **Codex、Claude Code、OpenCode、DeepSeek Harness、Antigravity CLI、Pi、Oh My Pi 和 MiniMax Code**。

这些工具仍然装在你自己的工作主机上，沿用你原本的登录凭据、模型订阅、`CLAUDE.md`、技能和 MCP 配置。Ait 不卖模型额度，也不试图替你改写各家供应商的数据处理规则；你在同一个界面里按任务挑趁手的工具，不用为换一个 Agent 重新适应一套操作习惯。各家 CLI 原生能力的差异，我们在[Agent 接入文档](/zh/docs/providers/)里如实列了出来。

## 把会话、代码、终端和 Git 放在一起

给 Agent 发完指令只是前半截，后面总要看改动、跑测试、修冲突、提 PR。

在 Ait 的工作区里，对话、目录树、Diff、终端和 Git 操作都在一起。同一仓库要并行开几个任务时，可以直接开独立 Worktree 或沙箱 Worktree；主机和任务变多以后，用**任务总览**按“待处理 / 运行中 / 待查看 / 已完成”一屏扫完所有卡点和结果，不用挨个点进去翻。

## 跑在自己的机器上，从手边的屏幕连进去

Ait 的后台服务用 Rust 写成一个轻量 daemon：

- 在 macOS 和 Linux 上装桌面版，会自动启动内置 daemon；只在本机用，不需要注册或登录 Ait 账户。
- 无桌面的 Linux 服务器或常开的 Mac mini 可以直接跑单文件独立 `aitd`。
- 登录同一账户后，桌面（含 Windows 客户端）、iOS、Android 和 [Ait for Web](https://aitapp.cn/) 都能通过在线服务连上你的工作主机；可信内网或 SSH 场景也支持免账户直连。

如果你想试试看，可以从 [下载页](/zh/download/) 获取对应平台版本，跟着 [快速上手](/zh/docs/quick-start/) 接入第一个 Agent，也可以直接去 [GitHub](https://github.com/ait-app/ait) 看源码和最近的更新记录。

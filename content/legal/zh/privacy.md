本政策适用于 **Ait** 桌面与移动应用、Ait 运营的账户与中继服务，以及 **ait-app.com** 网站。Ait 是在工作电脑上运行和连接 AI Agent 的工作空间。如对本政策有疑问，请联系 **[support@ait-app.com](mailto:support@ait-app.com)**。

## Ait 处理的信息

具体处理哪些信息，取决于你使用的功能和连接方式。

| 信息类型 | 用途与处理方式 |
| --- | --- |
| 项目目录、文件、Git 变更、提示词、会话、工具结果、终端输入与输出 | 用于运行 Agent 和展示工作区。项目文件与 Agent 运行时位于工作主机；连接的客户端可以通过相应连接访问你使用的内容。 |
| 应用设置、已保存主机、服务地址和连接凭据 | 用于记住偏好与验证连接。原生账户凭据在可用时使用平台安全存储；浏览器客户端使用浏览器存储。Agent 凭据由各自的原生 CLI 单独管理。 |
| 账户标识、已验证邮箱或手机号、显示名称、关联登录身份、账户状态与有效期 | 用于创建或验证账户、控制访问、关联设备。托管登录流程使用 Authing，以及你选择的 Google、微信等身份提供方。 |
| 安装与节点标识、设备或主机名称、平台、应用版本、主机标识和连接或会话状态 | 用于注册设备、发现获授权主机，以及建立和撤销中继访问。 |
| 音频、转写文本及你主动附加的文件或图片 | 在使用相关功能时提供语音输入、语音输出和 Agent 上下文。音频或文本可能由本地引擎或工作主机配置的语音服务处理；附件可能发送给你选择的 Agent 供应商。 |
| 推送通知令牌、通知文本、会话或路由标识 | 通过 Expo 与平台推送服务提供已启用的移动提醒。令牌保存在客户端，并向工作主机注册。通知内容可能包含任务或 Agent 信息。 |
| 你向客服提供的邮箱或手机号、消息与诊断信息 | 用于回复申请及排查问题。发送反馈前，请移除秘密信息和无关项目内容。 |

托管、账户与登录服务还会处理 IP 地址、请求时间等网络和请求信息，用于提供服务与保护访问安全。

## 本地运行与远程连接

本地运行不表示所有操作都留在设备内。Agent 会按自身配置与对应供应商通信。连接另一台设备时，工作区内容会在客户端与工作主机之间传输。

账户中继通过账户服务转发这些流量。中继是受信任的中间方；传输加密不等于中继端到端加密。服务可以处理流经它的内容，包括会话、文件传输和终端流量。直接连接使用你配置的主机地址和传输方式。

使用自建账户或中继服务时，该服务的数据处理由其运营方负责。连接模型见[连接与数据](/zh/docs/connection/)。

## 服务提供方与信息共享

提供你使用的功能时，相关信息会按需要共享给：

- **身份认证服务**：Authing 及你选择的身份提供方处理登录信息；Ait 接收账户所需的身份与已验证联系方式。托管登录页面中输入的密码由对应登录服务处理。
- **Agent 与语音服务**：你选择的 Agent、模型及语音供应商接收任务所需的请求、上下文、附件、音频或文本。其保留与训练方式取决于你的供应商账户和配置。
- **通知服务**：开启移动推送时，Expo 与平台推送服务会处理设备推送令牌与通知内容，以发送提醒。
- **基础设施与客服服务**：托管、网络及邮件服务提供方处理提供网页、账户与中继连接、客服邮件所需的信息。
- **获授权设备**：你连接到工作主机的客户端通过该连接接收工作区内容。

外部服务有各自的隐私条款，发送敏感内容前请先查阅。法律要求，或保护服务与用户确有必要时，我们也可能披露相关信息。

## 权限与网站存储

相关功能可能申请麦克风权限用于语音输入，相机、照片或文件访问用于附件，以及通知权限用于提醒。你可以在设备设置中撤销权限；撤销后对应功能会受到限制。

宣传网站未使用分析脚本、广告像素或非必要 Cookie。文档搜索读取本站静态搜索索引。托管服务提供方可能保留访问与安全日志。独立的账户控制台及登录服务会使用存储或 Cookie 维持认证会话。

## 数据保留

工作主机上的项目与 Agent 数据由你掌控，直至你主动删除。卸载移动应用不会移除该主机上的文件、会话或供应商记录。

Ait 运营的线上服务没有为账户、日志和备份设置固定保留期限，相关数据按提供服务和管理访问所需保留。你可以通过 **[support@ait-app.com](mailto:support@ait-app.com)** 申请删除账户或关联数据，具体步骤见[账户与数据删除](#data-deletion)。

设备与主机记录按提供在线服务和管理访问所需保留。短期登录票据与会话会到期，但到期或退出登录不等于删除账户。客服通信按处理申请及后续跟进所需保留。

为防止已停用或已删除的身份与主机重新激活，部分授权与撤销记录会继续保留。安全、法律义务或备份所需的记录，可能在账户停止访问后仍然存在。请联系支持了解适用于具体申请的保留情况；第三方服务及你自己的备份另有保留方式。

## <span id="data-deletion">账户与数据删除</span>

无需重新安装应用或登录网站，即可发起删除申请：

1. 发送邮件至 **[support@ait-app.com](mailto:support@ait-app.com?subject=Ait%20account%20and%20data%20deletion)**，主题填写 **Ait 账户与数据删除**。
2. 提供 Ait 账户使用的邮箱或手机号，并说明要删除整个账户还是指定数据。使用自建服务时，请说明服务运营方或服务地址。
3. 我们可能请你验证账户归属。请勿发送密码、验证码、daemon 令牌或供应商 API Key。

申请可涵盖 Ait 账户资料、关联登录身份、注册设备与主机信息，以及关联的在线服务数据。如安全或法律原因需要保留某些记录，我们会说明具体情况及备份的处理方式。仅停用账户或退出登录不会永久删除这些记录。

工作区本地数据需要在工作主机上删除，并清理你掌控的副本或备份。如不确定要删除哪些数据，可以联系支持。删除 Ait 账户不会删除源代码仓库、模型供应商账户或其他独立管理的账户；这些数据应向对应提供方另行申请删除。

## 你的选择与安全

你可以断开主机、退出登录、停止主机同步、撤销设备权限，并选择自己的 Agent 和服务配置。如需访问、更正或删除 Ait 持有的信息，或反馈隐私问题，请联系支持。可行使的权利取决于你所在地区。

运营的账户服务使用 HTTPS/WSS 与访问控制。原生客户端在可用时使用平台安全存储。直接连接或自建服务的安全性也取决于你的网络与配置。请妥善保管连接令牌，只连接你信任的设备。

## 儿童信息

Ait 面向使用开发工具的人群，不以 13 岁以下儿童为目标用户。如你认为儿童向 Ait 运营的服务提供了个人信息，请联系支持，以便核查和处理。

## 政策更新与联系

数据处理方式发生变化时，我们会更新本页，并在页面顶部标明更新日期。使用支持、隐私问题或数据申请，请发送邮件至 **[support@ait-app.com](mailto:support@ait-app.com)**，或访问[文档与支持](/zh/docs/)。

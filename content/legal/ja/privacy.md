このポリシーは、**Ait** のデスクトップアプリとモバイルアプリ、Ait が運営するアカウントサービスとリレーサービス、および Web サイト **ait-app.com** に適用されます。Ait は、作業用コンピューター上で AI エージェントを実行し、接続するためのワークスペースです。このポリシーに関するお問い合わせは、**[support@ait-app.com](mailto:support@ait-app.com)** までご連絡ください。

## Ait が処理する情報

処理される情報は、ご利用の機能と接続方法によって異なります。

| 情報 | 目的と取り扱い |
| --- | --- |
| プロジェクトのディレクトリ、ファイル、Git の変更、プロンプト、会話、ツールの実行結果、ターミナルの入出力 | エージェントを実行し、ワークスペースを表示するため。プロジェクトのファイルとエージェントのランタイムは作業ホスト上にあります。接続されたクライアントは、その接続を通じて、ご利用の内容にアクセスできます。 |
| アプリの設定、保存したホスト、サービスのアドレス、接続用の認証情報 | 設定を記憶し、接続を認証するため。ネイティブのアカウント認証情報は、利用可能な場合はプラットフォームのセキュアストレージを使用し、ブラウザークライアントはブラウザーのストレージを使用します。エージェントの認証情報は、それぞれのネイティブ CLI が個別に管理します。 |
| アカウント識別子、確認済みのメールアドレスまたは電話番号、表示名、連携したサインイン ID、アカウントの状態、有効期間 | アカウントを作成または認証し、アクセスを制御し、デバイスを関連付けるため。ホスト型のサインインフローでは、Authing と、Google や WeChat など、お客様が選択する ID プロバイダーを使用します。 |
| インストール ID とノード ID、デバイス名とホスト名、プラットフォーム、アプリのバージョン、ホスト識別子、接続とセッションの状態 | デバイスを登録し、認可されたホストを検出し、リレーのアクセスを確立および取り消すため。 |
| 音声、文字起こし、添付することを選んだファイルや画像 | これらの機能を利用する場合に、音声入力、音声出力、エージェントへのコンテキスト提供をするため。音声やテキストは、ローカルのエンジン、またはお客様のホストに設定された音声サービスで処理される場合があります。添付ファイルは、お客様が選択したエージェントプロバイダーに送信される場合があります。 |
| プッシュ通知トークン、通知のテキスト、セッション識別子やルーティング識別子 | 有効にしたモバイル通知を、Expo とプラットフォームのプッシュサービスを通じて配信するため。トークンはクライアントに保存され、作業ホストに登録されます。通知の内容には、タスクやエージェントの情報が含まれる場合があります。 |
| サポートに送信するメールアドレスまたは電話番号、メッセージ、診断情報 | リクエストに対応し、報告された問題を調査するため。報告を送信する前に、シークレットや、無関係なプロジェクトの内容は削除してから送信してください。 |

ホスティング、アカウント、サインインの各サービスも、サービスを提供しアクセスを保護するために、IP アドレスやリクエスト時刻などのネットワーク情報とリクエスト情報を処理します。

## ローカル実行とリモート接続

ローカル実行は、すべての操作がお使いのデバイス内にとどまることを意味しません。エージェントは、それぞれの設定に従ってプロバイダーと通信します。別のデバイスを接続すると、ワークスペースの内容がクライアントと作業ホストの間でやり取りされます。

アカウントリレーは、この通信をアカウントサービス経由で転送します。リレーは信頼できる仲介者であり、通信経路の暗号化があっても、リレーがエンドツーエンドで暗号化されるわけではありません。サービスは、会話、ファイル転送、ターミナルの通信を含め、通過する内容を処理できます。直接接続では、お客様が設定したホストのアドレスとトランスポートを使用します。

セルフホストのアカウントサービスまたはリレーサービスを選択した場合、そのサービスにおけるデータの取り扱いは、その運営者が管理します。接続モデルについては、[接続とデータ](/ja/docs/connection/)を参照してください。

## サービスプロバイダーと共有

データは、お客様が利用する機能の運営に必要な範囲で共有されます。

- **認証:** Authing とお客様が選択した ID プロバイダーがサインイン情報を処理します。Ait は、アカウントに必要な ID と確認済みの連絡先情報を受け取ります。ホスト型のサインインページに入力したパスワードは、そのサインインプロバイダーが取り扱います。
- **エージェントと音声:** お客様が選択したエージェント、モデル、音声のプロバイダーは、お客様が開始したタスクに必要なリクエスト、コンテキスト、添付ファイル、音声、テキストを受け取ります。データの保持やトレーニングへの利用に関する取り扱いは、お客様のプロバイダーアカウントと設定によって異なります。
- **通知:** モバイルのプッシュ通知を有効にすると、Expo とプラットフォームのプッシュサービスが、通知を配信するためにデバイスの配信トークンと通知ペイロードを処理します。
- **インフラストラクチャとサポート:** ホスティング、ネットワーク、メールの各プロバイダーが、ページの配信、アカウント接続とリレー接続の運用、サポートメールへの対応に必要な情報を処理します。
- **認可されたデバイス:** 作業ホストに接続したクライアントは、その接続を通じてワークスペースの内容を受け取ります。

外部サービスには、それぞれ独自のプライバシー条件があります。機密性の高い内容を送信する前に確認してください。また、法律で求められる場合や、サービスとそのユーザーを保護するために必要な場合は、情報を開示することがあります。

## 権限と Web サイトのストレージ

機能によっては、音声入力のためのマイクへのアクセス、添付のためのカメラ、写真、ファイルへのアクセス、通知のための通知権限を求める場合があります。これらの権限は、デバイスの設定で取り消せます。権限を取り消すと、関連する機能が制限されます。

マーケティングサイトでは、分析スクリプト、広告ピクセル、必須でない Cookie は使用しません。ドキュメント検索には、サイトの静的な検索インデックスを使用します。ホスティングプロバイダーが、アクセスログとセキュリティログを保持する場合があります。別個のアカウントコンソールとサインインサービスは、認証済みセッションを維持するために、ストレージまたは Cookie を使用します。

## 保持

作業ホスト上のプロジェクトとエージェントのデータは、お客様が削除するまで、お客様の管理下に置かれます。モバイルアプリを削除しても、ホスト上のファイル、会話、プロバイダーの記録は削除されません。

デーモンが自動的に生成するローカルのインシデント証跡はローテーションされ、7 日間、20 ファイル、5 MiB が上限です。容量の制限により、それより早く削除される場合があります。この証跡が自動的にアップロードされることはありません。エクスポートした診断ファイルとネイティブエージェントのログは、このクリーンアップポリシーの対象外であり、お客様または対応するツールが管理します。

Ait が運営するオンラインサービスでは、アカウントの記録、ログ、バックアップに固定の保持期間は設けていません。これらの情報は、サービスの提供とアクセス管理に必要な間、保持されます。アカウントまたは関連データの削除は、**[support@ait-app.com](mailto:support@ait-app.com)** にメールでリクエストできます。手順は[アカウントとデータの削除](#data-deletion)を参照してください。

デバイスとホストの記録は、オンラインサービスの提供とアクセス管理に必要な間、保持されます。有効期間の短いログインチケットとセッションは失効します。失効やサインアウトは、アカウントの削除ではありません。サポートとのやり取りは、リクエストの処理とフォローアップに必要な間、保持されます。

無効化または削除された ID やホストが再び有効にされるのを防ぐため、認可と取り消しに関する一部の記録は保持されます。セキュリティ、法的義務、バックアップのために必要な記録は、アカウントへのアクセスが終了した後も残る場合があります。お客様のリクエストに適用される保持の詳細については、サポートにお問い合わせください。サードパーティのサービスとお客様ご自身のバックアップには、それぞれ別の保持方針があります。

## <span id="data-deletion">アカウントとデータの削除</span>

アプリを再インストールしたり、Web サイトにサインインしたりしなくても、削除をリクエストできます。

1. 件名を **Ait account and data deletion** として、**[support@ait-app.com](mailto:support@ait-app.com?subject=Ait%20account%20and%20data%20deletion)** にメールを送信してください。
2. Ait アカウントに使用しているメールアドレスまたは電話番号を記載し、アカウント全体の削除を希望するのか、特定のデータの削除を希望するのかを伝えてください。セルフホストのサービスの場合は、その運営者またはサービスのアドレスを明記してください。
3. 所有者であることの確認をお願いする場合があります。パスワード、確認コード、デーモントークン、プロバイダーの API キーは、絶対に送信しないでください。

リクエストの対象には、Ait アカウントのプロフィール、連携したサインイン ID、登録したデバイスとホストの情報、および関連するオンラインサービスのデータを含められます。セキュリティまたは法的な理由で保持が必要な記録と、バックアップの取り扱いについては、こちらからご説明します。アカウントの無効化やサインアウトだけでは、これらの記録は完全には削除されません。

ローカルのワークスペースデータを削除するには、作業ホスト上でデータを削除し、お客様が管理しているコピーやバックアップも削除してください。削除すべきデータの特定でお困りの場合は、サポートにお問い合わせください。Ait アカウントを削除しても、ソースリポジトリ、モデルプロバイダーのアカウント、その他の独立して管理されているアカウントは削除されません。それらについては、各プロバイダーに別途削除をリクエストしてください。

## お客様の選択とセキュリティ

お客様は、ホストの切断、サインアウト、ホストの同期の停止、デバイス権限の取り消しを行えるほか、ご自身のエージェントとサービスの構成を選択できます。Ait が保有する情報へのアクセス、訂正、削除をリクエストする場合や、プライバシーに関する懸念を伝える場合は、サポートにお問い合わせください。利用できる権利は、お住まいの地域によって異なります。

運営しているアカウントサービスでは、HTTPS/WSS とアクセス制御を使用しています。ネイティブクライアントは、利用可能な場合はプラットフォームのセキュアストレージを使用します。直接接続やセルフホストの接続のセキュリティは、ネットワークと設定にも左右されます。接続トークンは秘密にし、信頼できるデバイスのみを接続してください。

## 子ども

Ait は、開発者向けツールを利用する人を対象としており、13 歳未満の子どもを対象としていません。Google Play 版は 18 歳以上の成人を対象としています。地域のストアのコンテンツ評価によっては、さらに高い年齢が必要になる場合があります。子どもが Ait の運営するサービスに個人情報を提供したと思われる場合は、調査と対応のため、サポートにお問い合わせください。

## 変更と連絡先

データの取り扱いが変わる場合は、このページを更新し、上記に更新日を表示します。サポート、プライバシーに関するご質問、データに関するリクエストは、**[support@ait-app.com](mailto:support@ait-app.com)** にメールするか、[ドキュメントとサポート](/ja/docs/)をご覧ください。
